配置 Kiwix Server ，实现离线访问维基百科

 2026.10.30  2026.10.30  奇技与淫巧  1644  4 分钟  

Kiwix 是一个离线访问网络内容的工具。作为应用程序，它可以运行在包括
Android, Linux, Mac OS, iOS 和 Windows 等多个平台上。同时也可以作为 Chrome, Firefox 和 Edge 等浏览器的扩展。

程序是内容的入口， Kiwix 访问的内容是一系列存储在后缀为 .zim 的文件中的数据。所以，通常 Kiwix 的使用方式是，首先下载所需平台的 Kiwix 应用程序。地址为
https://kiwix.org/en/applications/
然后根据需求下载对应的 zim 数据文件。具体可以访问
Kiwix 的图书馆页面
该页面收集了丰富的知识内容，如维基项目、古腾堡项目等等，可根据语言和项目类别进行筛选，按需下载。

屏幕阅读器用户特别推荐使用 Chrome 插件 Kiwix 进行操作，个人体验近似于通过服务器程序共享的网页前端。

除此之外， Kiwix 提供了一个工具，可以将知识库共享给同一网络环境中的其他设备。该工具一般是随应用分发的，也有其独立版本。只需简单配置，我们就可以在局域网内搭建一个离线的百科查询服务。使用这种方式有几个好处：

  1. 发起服务的设备负责存储知识内容，减少冗余备份；
  2. 同一网络下的设备无需特别安装 Kiwix 应用，只要通过设备中的浏览器就可以查询数据；
  3. 相比于桌面版的 Kiwix ，网页版会给辅助技术，如 NVDA ，提供更友好的使用体验，至少在 Windows 上是这样。

接下来就谈谈，不使用 Kiwix 应用，如何配置一个可以让内网设备直接通过浏览器访问的 Kiwix 离线数据查询服务。

下载 Kiwix Server

以 Windows 平台为例。浏览器访问
Kiwix 应用下载页

如果使用 NVDA 屏幕阅读器，可以通过点击字母 H 快速在网页的标题之间跳转。

靠前的是各个平台的 Kiwix 应用程序，它们不是本文的目标，因此可以一掠而过，直到
Kiwix Server 的部分。
自此处往下，找到 Windows 版本的超链接
Windows X86 64 bits binaries ，点击下载即可。

将下载回来的压缩包解压，可以获得三个文件：

  • kiwix-manage.exe： 用于管理离线图书馆，也就是 zim 文件
  • kiwix-search.exe： 一个命令形搜索程序，这篇文章中用不到
  • kiwix-serve.exe： Kiwix 服务器的主进程

它们都是命令行程序，所以后续步骤涉及一些需要在终端中进行的操作。

配置离线图书馆

主要是两步，第一，添加我们想要的 zim 文件，第二，载入 zim 文件并启动服务。

zim 文件的下载页在前言中有提到，这里不再赘述。

新建一个文件夹，叫什么都好，统一存放下载回来的 zim 文件，比如我在 E 盘下新建了一个名为 wiki 的文件夹。。

接下来，打开前一节解压的 Kiwix 工具所在的目录，在该目录下按下 Alt + D ，键入 cmd ，然后回车。鹧将在当前路径下打开命令提示符。

在命令提示符下进行的第一项操作是创建图书馆配置，指令为：

kiwix-manage library.xml add library.zim

指令中的 kiwix-manage 即我们在上一节中提到的用于管理 zim 文件的程序；其后的第一个参数为图书馆配置的路径；然后是 add 这代表添加 zim 文件；最后是 zim 文件的路径。比如

kiwix-manage e:\wiki\library.xml add e:\wiki\wikibooks_en_all_maxi_2021-03.zim

该指令表示在 E 盘的 wiki 文件夹中查找 library.xml 配置文件，如果没有就创建一个，然后将同一目录中的一个存储 Wikibooks 的 zim 数据文件添加到配置文件中。

如果该操作成功执行，打开 E 盘下的 wiki 文件夹，应该可以找到一个名为 library.xml 的文件。其内容应该与下面样例相似：

<library version="20110515">
    <!-- 叽里呱啦一大堆，字数太多，不贴了 -->
    </library>

添加多个 zim 文件可以照此进行，如：

kiwix-manage e:\wiki\library.xml add 1.zim
kiwix-manage e:\wiki\library.xml add 2.zim
kiwix-manage e:\wiki\library.xml add 3.zim

现在，载入这个 library.xml 即可启动 Kiwix 服务，指令如下：

kiwix-serve --library e:\wiki\library.xml

kiwix-serve 是 Kiwix 服务器主程序，其后的选项 --library 需要我们给出一个 library.xml 配置的路径作为参数。这里将刚才创建的 e:\wiki\library.xml 作为其参数。回车之后，输出应类似下面的内容：

Loading the library from the following files:
        e:\wiki\library.xml
The library was successfully loaded.
The Kiwix server is running and can be accessed in the local network at: http://192.168.2.110:80

注意最后一行的地址
http://192.168.2.110:80
这就是局域网内其他设备用于访问 Kiwix 服务的地址。

此时，打开浏览器然后输入该地址，即可访问 Kiwix 服务页面，预览和查询本地图书馆内存储的数据。

一点小改进

直接在命令提示符中运行服务要求我们维持命令提示符的打开状态，否则 Kiwix Server 就会罢工。所以我们需要让 Kiwix Server 转到后台默默奉献。

操作如下。

新建一个文本文档，然后，将以下内容填入该文本文档

@echo off
if "%1"=="h" goto begin
start mshta vbscript:createobject("wscript.shell").run("""%~nx0"" h",0)(window.close)&&exit
:begin
kiwix-serve --library e:\wiki\library.xml > ./output.txt

微调最后一行，将其中的 e:\wiki\library.xml 改为你的 library.xml 的路径。

完成修改后保存文件。将文本文件的后缀名从 .txt 改为 .bat 。

现在，只要双击或回车运行该 bat 文件就可以后台启动一个 Kiwix 服务，同时，在 该 bat 文件所在的目录下会生成一个 output.txt 文件，其中保存了指令执行后的输出信息。如果忘记了访问服务的 http 地址，可以到输出文件中查看。

End.
